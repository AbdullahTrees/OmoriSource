# meetox80/omori input script for T8 (frame numbers, 60 fps cap).
#
# Changes from the draft (tools/meetox-bench.txt as handed over):
#  1. The draft's two "press ok" started the new-game intro and its autorun event kept running
#     through every warp (shots showed "EVERYTHING IS GOING TO BE OKAY" / "DON'T WORRY..." text,
#     not the maps). This follows the engine's own tests (engine/tests/psp1000/kc.txt): one
#     "press ok" past the splash, then warp straight to a map.
#  2. Because White Space (87) starts OMORI's intro cutscene, every warp is followed by the eval
#     from engine/tests/psp1000/maps.txt that clears the message window, the map interpreter and
#     leftover screen pictures/tone, so the shot shows the map itself.
#  3. Party members 2-4 are added once (kc.txt) so follower sprites exist as in a real playthrough.
#  4. "eval console.log" lines mark each phase in the log (console.log -> plat::log, stderr).
#
# Dwell per map: 420 frames (~7 s at the 60 fps cap, longer on a slow map); shot 40 frames
# before the next warp.
